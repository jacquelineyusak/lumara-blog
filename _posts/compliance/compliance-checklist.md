A company compliance register is a working list of obligations, documents, changes and follow-up tasks. For a business in Bali, it should connect each item to the actual company and activities rather than repeat a generic checklist with no owner.

Start with the company’s current documents and existing reporting position. Ask the relevant provider to confirm what applies, then record the basis for that conclusion.

## Keep six fields for every item

| Field | Purpose |
| --- | --- |
| Item and business context | Name the document, report or change and the company activity it relates to |
| Current position | Record the latest status and where the supporting evidence is stored |
| Next action | Describe a concrete step, such as obtaining a missing document or reviewing a change |
| Owner | Name the person responsible for progressing it |
| Date and source | Record the verified deadline or next review date and its basis |
| Completion evidence | Link the final document, submission acknowledgement or review note |

Keep a separate status for an item awaiting professional review. “Not yet confirmed” is more useful than an unsupported green tick.

## Review changes as they happen

Add a review whenever the business changes an activity, location, staffing arrangement, ownership or administrative contact. These are prompts to assess the records and obligations, not a claim that every change triggers the same filing.

For example, opening another operating location should trigger a check of what the company already holds, what the planned activity requires and who will confirm the next steps. Record that review before assuming an existing document covers the new situation.

## Separate records from actions

A document folder answers “what do we hold?” The register answers “what happens next?” Link the two. If a file is missing, name the person obtaining it. If a submission needs a response, record the follow-up separately from the initial submission.

Maintain a version history for significant changes. Keep the final approved document distinct from working drafts so that the wrong version is not reused later.

## Set a repeatable review

Choose a regular internal review suitable for the business. Check open items, upcoming dates and changes since the previous review. Close completed tasks only when their evidence is saved, and give unresolved tasks a specific next action.
